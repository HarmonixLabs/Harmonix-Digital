# How to Find Your Pipedream API Key

## Step-by-Step Instructions:

### 1. Go to Pipedream
- Open [pipedream.com](https://pipedream.com) in your browser
- Log into your account

### 2. Navigate to API Keys
- Click on your **profile picture** (top right corner)
- Select **"Settings"** from the dropdown
- In the left sidebar, click **"API"**

**OR**

- Direct link: [pipedream.com/settings/api](https://pipedream.com/settings/api)

### 3. Create or Copy API Key
- You should see an **"API Keys"** section
- If you don't have a key yet, click **"Create API Key"**
- If you already have one, click **"Copy"** next to the key
- The key will start with `pd_` (like `pd_abc123def456...`)

### 4. Alternative Location
If you can't find it in Settings → API, try:
- Go to your **Account** settings (profile menu)
- Look for **"Developer"** or **"API Keys"** tab
- Some accounts may have it under **"Integrations"**

### 5. If Still Can't Find It
The API keys section might be in:
- **Account** → **Developer Settings**
- **Workspace Settings** → **API**
- **Profile** → **Developer** → **API Keys**

### 6. What the API Key Looks Like
```
pd_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz567
```
- Always starts with `pd_`
- Long string of letters and numbers
- Usually around 50+ characters

### 7. Security Note
- Keep this key secure - don't share it publicly
- It gives access to trigger your Pipedream workflows
- You can regenerate it if needed
