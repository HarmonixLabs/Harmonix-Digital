## 🧩 Agent Creation Form (`/create-agent`)

Build a wizard-like form (multi-step or accordion):

### Step 1: Agent Basics
- Name
- Purpose / tagline
- Creator name
- Pricing (monthly fee)
- Category (e.g. Sales, Ops, Content)

### Step 2: Technical Details
- Token draw estimate
- Integrations (Gmail, Notion, Slack, etc.)
- Supported Use Cases (dropdown)

### Step 3: Upload
- Icon/logo (PNG, JPG, or SVG)
- Description + Benefits (Markdown editor)

### Step 4: NFT Mint (optional)
- Button to trigger “Mint Agent NFT” modal

📁 Save form data to CMS (supabase, sanity, or markdown system)
