## 💳 Stripe Integration

### Backend
- Connect Stripe live/test keys
- Create `POST /api/checkout-session`:
  - Receives: plan ID, deposit %, metadata
  - Returns: Stripe `session.url`

### Frontend
- On “Proceed to Payment”:
  - Call backend
  - Redirect to `session.url`
  - Success URL → `/thank-you?payment=success`
  - Cancel URL → `/checkout?payment=cancelled`

### Tiers
| Plan       | Setup Fee       | MRR           | Deposit (15–33%) |
|------------|------------------|---------------|------------------|
| Starter    | $4,400–$6,200    | $800–$1,200   | $666–$2,000      |
| Growth     | $8K–$12.5K       | $3.2K–$4.4K   | $1.2K–$4.1K      |
| Expansion  | $15K–$18K        | ~$6K          | $2.2K–$6K        |
| Enterprise | $21.5K+          | $8K+          | Custom           |

## 🤖 SŌL Brain Integration

- `/sol-brain` form → asks for:
  - Industry, team size, current tools
- Returns:
  - Suggested agents
  - Estimated ROI
  - “Deploy Agent” → prefilled checkout

## 🧠 Agent Marketplace + Creator Logic

### `/marketplace`
- Agent Cards show:
  - Monthly fee (primary)
  - Flip = integrations, tools, token usage
  - “Learn More” = `/marketplace/[agent-slug]`
  - “Deploy Agent” = redirects to checkout/signup

### Agent CMS Template
- Name, Creator, Integrations, Use Cases
- Token estimate
- Available for deployment / mint

## 🔗 NFT + Minting Logic (Testnet)

### Agent NFTs
- Deployed to polygon testnet
- Metadata includes:
  - creator wallet
  - monthly fee
  - tier
  - integrations

### Creator Royalties
- Stripe Connect or crypto wallet
- Standard royalty config:
  - Platform: 15%
  - Creator: 70%
  - Investor: 15%

## 📤 Onboarding Flow (Post Payment)

1. Payment success → `/thank-you`
2. CRM tag → GoHighLevel
3. Trigger email onboarding sequence
4. Setup wizard launches in dashboard
5. SŌL helps user activate 1st agent
