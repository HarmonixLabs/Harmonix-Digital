## 🚀 Quick Start Guide

### 1. Automated Deployment (Recommended)
```bash
# Run the automated deployment script
./deploy_harmonix.sh
```

### 2. Manual Setup
```bash
# Backend setup
cd harmonix-backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python init_db.py

# Frontend setup
cd ../harmonix-platform
npm install
npm run build
```

### 3. Start the Platform
```bash
# Start HARMONIX platform
./start_harmonix.sh

# Check platform health
./health_check.sh
```

