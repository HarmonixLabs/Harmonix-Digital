✅ 2. CHAT LOGIC – 3-MODE WORKFLOW FLOW

DISCOVERY MODE (Default Start State):

Purpose: Ask context-building questions and qualify the lead.

Agent behavior:
	•	2–3 natural language prompts like:
	•	“Tell me about your current goals.”
	•	“What are your biggest roadblocks?”
	•	“What’s your timeline or urgency?”
	•	Once data collected → pass context into agent memory and upgrade to strategy mode.

UI:
	•	Tag “Discovery Complete ✅” → Transition to Strategy Mode

⸻

STRATEGY MODE:

Purpose: Output tailored strategic blueprint based on Discovery data.

Agent behavior:
	•	Suggests a 3–step or 5–step gameplan
	•	Highlights tools/automations it would use if deployed
	•	Shows estimated ROI/impact if executed

User sees:
✅ Gameplan visual (simple card UI)
✅ Summary list of strategy steps
✅ Prompt: “Do you want to move to Execution Mode?”

Button: Yes, Let’s Execute 🚀

⸻

EXECUTION MODE:

Purpose: Convert curiosity into commitment.

3 Call-To-Action buttons:
	•	🔒 Join Waitlist → Collect email + confirmation → trigger HarmonyEmailBot
	•	💎 Reserve My Spot → Go to Stripe checkout flow
	•	⚙️ Pick a Plan → Modal with tier options (1 Agent, 3, 6, Full Suite)

After action, response:

“Thanks for confirming! You’ll receive your execution strategy + next steps by email. You can upgrade or schedule a setup call at any time.”
