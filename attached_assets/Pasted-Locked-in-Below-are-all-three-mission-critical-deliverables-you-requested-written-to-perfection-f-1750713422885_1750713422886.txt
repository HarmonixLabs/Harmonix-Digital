🧠 2. Instructions.md – Developer Deployment Plan for Marketplace

# 🧠 Harmony Agent Marketplace – Developer Instructions

## Objective:
Deploy a fully functional Agent Marketplace with dynamic card views, profile CMS, agent creation form, and wallet-connected permissions.

---

## 1. Marketplace Grid View
- Dynamic grid layout pulling agent data from CMS
- Each Agent Card:
  - Shows monthly MRR
  - Has tooltip for time saved, integrations, and token draw
  - Flips to show Deploy / Learn More
  - Responsive across desktop/tablet/mobile

---

## 2. Agent Profile Page (`/marketplace/agent-slug`)
- Dynamically generated CMS profile from form submission
- Sections:
  - Hero with avatar + stats
  - Time savings + use case grid
  - Integration icons (Zapier, Slack etc.)
  - Demo preview (if available)
  - Setup options: Base vs Custom
  - NFT ownership and royalties (if enabled)
  - CTA to Deploy or Chat with SŌL

---

## 3. Agent Creation Flow
- Route: `/create-agent`
- Access:
  - Wallet connected OR Harmony Account required
  - Free accounts limited to 1 agent
  - Creator subscriptions enable full access
- Form: Uses `AgentFormStructure` JSON
- On submission:
  - Agent is stored in CMS
  - If NFT toggle is enabled:
    - Trigger minting process via backend (IPFS + contract)
  - Added to marketplace if public
  - Added to creator’s dashboard

---

## 4. Checkout Integration
- "Deploy Agent" triggers Stripe Checkout
- Pass monthly MRR to payment
- On success:
  - Agent added to user dashboard
  - CRM (HighLevel) tagged
  - Token meter initialized
  - Sol sets up starter sandbox

---

## 5. Dashboard Integration (Post-Purchase)
- User can:
  - View installed agents
  - Interact via chat
  - View reports: time saved, task history, token use

---

## 6. Design Requirements
- Brand colors from Harmonix palette
- Consistent animations & spacing from homepage
- Sticky transparent header
- Mobile-first layout

---

## 7. Next Steps
- Integrate real agent data
- Hook up Stripe & Wallet APIs
- Complete `/create-agent` permissions
- Finalize Leaderboard logic for Top Agents
