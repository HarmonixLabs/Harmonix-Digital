✅ Stripe Checkout Flow

1. Agent Purchase Flow
	•	Users click “Deploy Agent” in Marketplace
	•	If logged in:
	•	Proceed to Stripe Checkout
	•	If not logged in:
	•	Redirect to /login?redirect=checkout
	•	Stripe collects:
	•	Agent Name
	•	Agent Tier
	•	Monthly Price (agent-controlled)
	•	Optional ROI estimate
	•	Post-purchase:
	•	Redirect to /thank-you?payment=success
	•	Trigger onboarding sequence (sol + dashboard setup)

2. Minimum Logic
	•	Minimum install pricing:
	•	Platform = $1,500+
	•	Agent = $350+ unless agent sets lower pricing
	•	Agent creators can set pricing as low as $20/month
	•	Add info icon: “Minimum Harmony agents start at $350/month unless custom pricing is set by creators.”

3. Stripe Connect
	•	Royalties split dynamically:
	•	Creator (default: 75–90%)
	•	Platform (fixed: 10–15%)
	•	Optional: Investor royalty (if NFT has a third wallet mapped)
