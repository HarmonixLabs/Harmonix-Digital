# Harmonix Platform - Replit Prompt

## Overview

Create a fully functional version of the Harmonix platform with at least 3-6 demo agents that people can interact with. The platform should include a protected backend that can only be accessed when logged in, a video demonstration of how the Harmony team works, and a complete user experience with no dead ends.

## Key Requirements

1. **Complete User Experience**
   - Map out the entire UX flow to create a closed loop experience
   - Ensure all buttons in the navbar and footer lead somewhere meaningful
   - Create all necessary pages for a complete testing environment

2. **Agent Marketplace**
   - Implement categories and filters for browsing example agents
   - Create interactive agent cards that flip to show detailed information
   - Add a lock mechanism for premium agents while still showing their info and abilities

3. **Demo Agents**
   - Implement 3-6 fully functional demo agents with different specializations
   - Include the core flagship agents: Sales Agent (Cash), Concierge Agent, HR Agent, etc.
   - Each agent should demonstrate its key capabilities and use cases

4. **Authentication System**
   - Implement secure login functionality for backend access
   - Create a demo mode for unauthenticated users with limited functionality
   - Ensure all protected routes require authentication

5. **Lead Capture Integration**
   - Connect all forms to GoHighLevel CRM as the primary destination
   - Add HubSpot as a secondary CRM integration
   - Implement Google Sheets as a backup mechanism for all lead data
   - Ensure robust error handling and retry logic for all integrations

6. **Video Demonstration**
   - Create a custom video player component to showcase how the Harmony team works
   - Implement responsive design for the video player
   - Add chapter navigation for key points in the video

## Technical Requirements

1. **Frontend**
   - Use Next.js/React with proper ES module syntax
   - Implement the design system with consistent tokens (colors, typography, spacing)
   - Ensure responsive design across all device sizes
   - Fix all existing module system conflicts and import/export issues

2. **Backend**
   - Create a Node.js/Express API with proper authentication
   - Implement secure API endpoints for agent interactions
   - Connect to necessary external services (CRM, etc.)
   - Ensure proper error handling and logging

3. **Design System**
   - Follow the established color palette (jade/gold)
   - Maintain consistent spacing using the 8px baseline grid
   - Implement micro-animations (150-300ms) for enhanced UX
   - Preserve hero animations (rain droplets, background grid, Jade/Gold layering)

## Implementation Approach

1. Research deeply across the codebase to understand the current structure
2. Identify all files and functions related to the requirements
3. Assess what needs to be modified or created to implement each feature
4. Develop a comprehensive plan with clear steps for implementation
5. Execute the plan systematically, ensuring all requirements are met

## Deliverables

1. A fully functional Harmonix platform with complete user flows
2. 3-6 interactive demo agents with different capabilities
3. Protected backend with authentication system
4. Robust lead capture system with multi-CRM integration
5. Comprehensive documentation of all implemented features

- Ensure all lead capture forms reliably send data to GoHighLevel, HubSpot, and Google Sheets
- Focus on creating a seamless, professional user experience with no dead ends
- Implement proper error handling and fallbacks throughout the application
