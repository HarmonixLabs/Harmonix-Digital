# 💸 Harmonix Phase 3 Developer Instructions – Pricing Table, Checkout Flow, Stripe Connect v1.0

This phase activates the pricing matrix, dynamic checkout, and payment pipeline for both new customers and agent marketplace buyers.

---

## 🛒 Pricing Table Design (`/pricing`)

Responsive table or card-based layout with 4 core plans:

| Plan        | Agents      | Setup Fee (One-Time)      | Monthly MRR       |
|-------------|-------------|----------------------------|-------------------|
| Starter     | 1 Agent     | $4,400 – $6,200            | $800 – $1,200     |
| Growth      | 3–5 Agents  | $8,000 – $12,500           | $3,200 – $4,400   |
| Expansion   | 6–8 Agents  | $15,000 – $18,000          | ~$6,000           |
| Enterprise  | 9–12+ Agents + SŌL | $21,500+             | $8,000+           |

✅ Optional CTA:
- “Reserve My Spot – 30% Off for First 280 Clients” → `/checkout?discount=earlybird`
- “Chat with SŌL to Find Your Plan” → `/sol-brain?usecase=diagnosis`

---

## ✅ Checkout Flow (`/checkout`)

Dynamic agent/package-based checkout engine.

### 1. Checkout Entry Points
- `/checkout?agent=xyz`
- `/checkout?plan=starter`
- `/checkout?deposit=444`

📌 If “agent” is selected:
- Pull agent data
- Show monthly fee
- Add optional setup fee if no Harmony system installed

📌 If “plan” is selected:
- Pull plan details
- Apply deposit amount (33% default or 15% if `?financed=true`)
- Optional: auto-prompt wallet connection

---

### 2. Checkout Form

Fields:
- Name
- Email
- Business Name
- Industry (optional)
- Tools You Use (tags, optional)
- Need Financing? (checkbox)

📌 Show:
- ROI Calculator
- Setup fee (based on plan selected)
- Monthly Fee (based on agents or plan)

---

### 3. Stripe Logic

#### Stripe API Setup
Use Stripe Checkout Session for both one-time setup + recurring.

Stripe Metadata:
```json
{
  "agent_slug": "sop-architect",
  "plan": "growth",
  "monthly_fee": 4400,
  "setup_fee": 9500,
  "wallet": "0xabc123",
  "email": "founder@brand.com"
}

Stripe Routes
	•	✅ success_url: /thank-you?status=success
	•	❌ cancel_url: /checkout?status=cancelled
	•	Optional upsell: “Join the waitlist for 30% off?”
