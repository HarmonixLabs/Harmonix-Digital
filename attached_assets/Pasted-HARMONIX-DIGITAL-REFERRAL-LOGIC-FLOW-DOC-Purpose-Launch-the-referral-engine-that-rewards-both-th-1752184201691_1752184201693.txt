HARMONIX DIGITAL — REFERRAL LOGIC FLOW DOC

Purpose:
Launch the referral engine that rewards both the inviter and the invited user with token usage, subscription discounts, and bonus perks. This doc outlines the backend logic, GHL tag flow, reward system, and infrastructure needed.

⸻

1. SYSTEM OVERVIEW

Referral Engine Name: Harmony Rise Loop
Referral Format: https://harmonixdigital.com?r={referrerID} or .ca

Each referrer receives a unique code. When someone signs up using that code:
	•	The referrer earns bonus tokens + monthly % discount (stackable)
	•	The new user receives welcome tokens + first-month discount

⸻

2. REFERRAL FLOW BREAKDOWN

🔗 STEP 1: LINK GENERATION
	•	Upon signup, system auto-generates a referral ID:
	•	ref=firstnamelastname123
	•	Stored in DB + displayed in user dashboard

🤝 STEP 2: NEW USER JOINS VIA LINK
	•	Referral parameter captured in browser
	•	Stored in cookie/localStorage (7-day expiry)
	•	On signup:
	•	Referral ID submitted as hidden field
	•	Triggers DB update & GHL webhook

🎁 STEP 3: REWARD ISSUED
	•	Referrer receives:
	•	+500 tokens
	•	-5% MRR discount (max -30%)
	•	Referee receives:
	•	+250 tokens
	•	-10% off first month
